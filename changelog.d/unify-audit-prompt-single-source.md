- **Changed:** `/mcp-server-stress` and `/mcp-server-surface-test` now share a single canonical audit prompt at `skills/mcp-server-surface-test/prompts/full.md`. The legacy `maintainer-overlay.md` (which duplicated ~85 % of `full.md`) is deleted. The two skills' behavioural delta is now driven by a new `--output-mode=findings|fragments` flag on `/mcp-server-surface-test`: `findings` (default) retains the consumer-facing dual-path emission (stdout-print / GitHub Issues per the existing maintainer-aware routing); `fragments` writes one `<audited-repo-root>/backlog.d/<finding-id>.md` per finding for `/backlog-intake` to consume. `/mcp-server-stress` survives as a thin maintainer-only alias that invokes `--output-mode=fragments`. Reports-path resolution auto-detects: `ai_docs/audit-reports/` is used when `ai_docs/` exists at the audited repo root, else top-level `audit-reports/`. Cross-repo `--target=<path>` advertising removed from `/mcp-server-stress` — the Roslyn MCP server's sanctioned-root restriction makes the cross-repo workflow structurally infeasible; open Claude Code in the target repo and run `/mcp-server-surface-test --output-mode=fragments` from there instead.
