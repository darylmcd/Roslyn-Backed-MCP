- **Fixed:** Shipped plugin `hooks/hooks.json` no longer registers the two command-based hooks (`PreToolUse:Edit|Write|MultiEdit` → `eng/guard-release-managed-files.ps1`, `PostToolUse:Edit|Write|MultiEdit` → `eng/verify-skills-on-edit.ps1`) that referenced repo-local scripts via `${CLAUDE_PROJECT_DIR}`. The scripts only exist in Roslyn-Backed-MCP, so on consumer installs pwsh was failing with exit 64 (`The argument '<consumer-repo>/eng/guard-release-managed-files.ps1' is not recognized as the name of a script file.`) on every Edit/Write/MultiEdit tool call — 8,398 silent hook failures across 88 sessions in 11 repos over a 14-day window per the 2026-05-21 BioRemote cross-repo retrospective. Both hooks moved to maintainer-only `.claude/settings.json` so they fire only inside this repo. The two prompt-based PostToolUse hooks (`mcp__roslyn__server_info` update reminder, `mcp__roslyn__*_apply` verification reminder) remain in the shipped plugin — consumers still benefit from those. Closes `roslyn-mcp-edit-hooks-mis-scoped-cross-repo`. Evidence: `C:\Code-Repo\BioRemote\ai_docs\reports\20260521T044946Z_bioremote_cc-automation-retro.md` §F1, R1.
