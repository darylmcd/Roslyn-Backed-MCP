- **Fixed:** `extract_interface_preview` with `replaceUsages` now retypes every declaration spelling of the concrete type (qualified, `global::`-qualified, aliased, return types, properties, locals, `foreach`/`out var` variables, tuple elements, and generic-argument, array and nullable forms, including the matching `new List<T>()` / `new T[n]`) instead of only a bare parameter or field, leaving construction, static access, `typeof`, casts and `is`/`as` concrete, and it refuses instead of publishing a partly rewritten preview: an unavailable post-generation compilation or an unrebindable concrete type (previously a token lacking the requested rewrite) and, new for this route, a rewrite whose result would not compile (a consumer calling a member outside `memberNames`, a generic-variance or override mismatch), with the compiler ids listed. Migration: preview with `replaceUsages=false`, or include the members the consumers call in `memberNames`. Source-generated documents are skipped by name, and `dependency_inversion_preview` no longer drops a consumer document silently when its syntax or model is unavailable. Closes `interface-extraction-replacement-symbol-refusal` and `replace-concrete-usages-non-identifier-spellings`.
