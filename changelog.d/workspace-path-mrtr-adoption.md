- **Changed — BREAKING:** Workspace-path recovery, symbol disambiguation, and optional scaffold-name sampling now use request-scoped MRTR input on 2026-07-28 MCP requests, fail closed on request capabilities, reject malformed/stale responses, preserve cancellation and the selected workspace across retries, and sanitize fallbacks. Stateful 2025-11-25 sessions retain direct form elicitation, but legacy or sampling-incapable scaffold-name requests now use the deterministic placeholder instead of nested `sampling/createMessage`. Access-policy and operating-system `UnauthorizedAccessException` failures now expose the stable sanitized `PermissionDenied` category instead of `InternalError`. **Migration:** modern clients must resolve published input requests, treat any server-provided `requestState` as opaque, echo it byte-for-byte unchanged, and retry with the matching request-scoped input responses; clients that want sampled test-name suggestions must use the 2026-07-28 MRTR flow; legacy clients must accept deterministic scaffold names; error consumers should branch on `PermissionDenied` for access-policy or OS denial and must not parse raw exception text. The additive `_meta.autoResolution` value `request-state` identifies a retry pinned to its previously selected workspace. Closes `workspace-path-mrtr-adoption`, `symbol-choice-mrtr-adoption`, `mcp-sampling-mrtr-migration`, `elicitation-parameter-contract-single-source`, `elicitation-tryelicitchoice-swallow-path-coverage`, and `elicitation-choiceprompt-test-suite-consolidation`.
