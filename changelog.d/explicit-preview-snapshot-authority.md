- **Changed — BREAKING:** Graph stages and retained forks use dedicated `roslynmcp-staging` and `roslynmcp-forks` parents under the captured OS temporary directory. In-process `WorkspaceForkApplyService` callers must provide the required absolute dedicated fork-parent coordinate; the host supplies this default explicitly. Native recursive membership and condition proofs can refuse overlapping placement before namespace creation. Retained forks keep the existing 24-hour default expiry contract and require fresh client path grants for later public loads; retaining a fork does not copy the original workspace's grants. Public project status aggregates matching native target frameworks and test capability; producer-specific resolution still refuses ambiguous native contexts. See [ADR 0029](../docs/decisions/0029-explicit-preview-snapshot-authority.md). The next-major release hold remains unchanged. Physical source transitions use a dedicated `.roslynmcp-custody` administrative parent outside the original and independently staged desired graph's observations, on the source's actual filesystem. Permit service-parent creation/access under a qualifying existing temporary or source-ancestor anchor, together with the required workspace rename/delete permissions. If no same-filesystem disjoint anchor qualifies, the mutation refuses before moving source bytes; it never creates source-local staging ancestors or falls back into an observed source directory. In-process recovery authorities must implement the required operation-bound custody acquisition and retain its exact physical receipt for pending recovery. See [ADR 0029](../docs/decisions/0029-explicit-preview-snapshot-authority.md). Bind previews, physical mutations, restore/test processes and compiler images to owned snapshots, current path grants and recorded MSBuild contexts. In-process integrations must migrate the required preview, undo, image and phased test-runner interfaces together; gated executors must implement ExecuteAuthorizedAsync and both required ExecuteTestAsync callbacks: authorize immediately before effects, then collect raw execution results while the execution gates and linked timeout remain held and before outward redaction. Collect reports through the supplied owned-directory capability; printed report paths do not grant access. In-process analyzer consumers must retain the published owned references through the general AnalyzerReference contract; do not substitute native source references or require AnalyzerFileReference casts. Classic and native tests use frozen dependencies with --no-restore. Compiler certification may execute additional design-time targets: load trusted projects only; path checks do not sandbox native tasks. Invalid restore evidence can retain semantic loading but cannot grant compiler-image or mutation authority. Regenerate truncated previews and use their paired apply route. See [ADR 0029](../docs/decisions/0029-explicit-preview-snapshot-authority.md) for complete next-major migration requirements and the release hold. Physical writes and undo require operating-system permissions to move source entries through owned recovery custody, in addition to file-data write permission. Grant the executing account the necessary workspace rename/delete permissions and staging-directory access, or use a workspace copy with those permissions. Writable files with denied namespace permissions are refused without an unsafe overwrite fallback. Current path grants remain required; package restore cannot repair this permission refusal. See [ADR 0029](../docs/decisions/0029-explicit-preview-snapshot-authority.md). In-process `WorkspaceForkApplyService` construction now requires `TimeProvider` immediately after `forkParent`. Pass `TimeProvider.System` or the application-owned provider explicitly; the host supplies the system provider. See [ADR 0029](../docs/decisions/0029-explicit-preview-snapshot-authority.md#embedding-clock-migration). The next-major publication hold remains unchanged.
