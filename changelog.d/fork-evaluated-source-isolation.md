- **Changed — BREAKING:** Experimental workspace forks reject evaluated imports, inputs and restore outputs that reach the source workspace. Native load and build checks also guard package preprocessing, assets-cache writes and copied outputs, including late project references and physical aliases. Retained forks preserve these checks when reopened or tested. Fork capture refuses previews whose source workspace version changed while waiting. Source reload remains available after copying; canonical pools inside ordinary source trees preserve authored assets without recursive fork copying. Cleanup preserves independent link-target bytes and attributes. **Migration:** Forking a retained experimental workspace now creates a sibling in its outermost verified physical fork pool, preventing recursive path growth. Generated children now use reserved `.roslynmcp-fork-<timestamp>-<suffix>` names so canonical storage inside ordinary sources preserves SDK default source globs and parent watcher/preview authority; verified legacy names remain readable and expiry-compatible. Use the returned `forkPath`; do not derive its name or location from the immediate source. The current configured root and any client narrowing must authorize that pool and exact destination. Reopen with an authorized original root when a retained-only boundary refuses the sibling pool. Windows refuses an unlaunchable generated working directory before creating or sweeping storage; move or reopen the source under a shorter authorized root. See [ADR 0030](../docs/decisions/0030-retained-fork-storage-and-lifetime.md). Automatic expiry deletes only verified owned fork directories. Unmarked forks from before admission material was introduced, unrelated timestamp-shaped siblings and reparse-point entries are preserved; inspect and remove those manually when no longer needed. Expiry and cleanup preserve logically retained fork sources while another Apply waits for their shared pool, including sources inside legacy enclosing owners. Deletion admission refuses a later source Apply before copying, and failed workspace closure retains physical material with a cleanup warning. Closes `fork-evaluated-source-isolation`.
