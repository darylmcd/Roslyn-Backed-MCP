### Added

- **Added:** Shared finding-rendering helper at `skills/mcp-server-surface-test/lib/render-finding.ps1`. Single source of truth for the GitHub-Issue body shape used by both `/mcp-server-surface-test --auto-file` (consumer) and `/backlog-intake --publish` (maintainer). Exposes `Get-FindingRepoId` (kebab-case slug from `git remote get-url origin` with directory-basename fallback), `Test-FindingShouldRefusePublicFile` (P0 / `area: security` predicate), `Render-FindingBody` (deterministic Markdown body with anchors sorted alphabetically), `Render-FindingFragment` (full `backlog.d/<id>.md` content with YAML frontmatter), and `Render-FindingIssue` (title + labels + body + `refusedPublic` flag). The renderer prepends a SECURITY/P0 banner pointing at https://github.com/darylmcd/Roslyn-Backed-MCP/security/advisories/new whenever the refusal predicate fires — defense-in-depth so a misconfigured caller still ships the warning. Closes Row 2 of the move-to-git-issues design.
- **Added:** `--publish` flag on `/backlog-intake`. After Phase 6 commits the batch, files each accepted row as a public GitHub Issue at `darylmcd/Roslyn-Backed-MCP` via `gh issue create` using the shared renderer. P0 / `area: security` rows are never filed publicly — they print to stdout with the security-advisory escalation banner. Falls back to stdout-print + warning if `gh` is missing or unauthenticated. Closes the maintainer-side leg of Row 2's "exercise the schema and template by filing every accepted finding" goal.
- **Added:** `server_version` required frontmatter key on `backlog.d/` fragments per `ai_docs/items/backlog-d-fragment-schema.md`. Stamped from `server_info.version` at Phase -1 of every audit; lets the planner correlate findings to a specific server version when triaging regressions. `area: security` is now a member of the area enum and is the canonical token for triggering the public-filing refusal regardless of severity.
- **Added:** `tests/RoslynMcp.Tests/Skills/RenderFindingScriptTests.cs` with 11 tests pinning renderer determinism, alphabetical anchor sort, the variable-shadowing regression fix (`$finding` vs `$Finding` parameter), the P0/security refusal contract, banner placement, repo-id derivation from a `git remote` URL, repo-id fallback to the directory basename, and `server_version` frontmatter emission. No live `gh` invocation in any test.
