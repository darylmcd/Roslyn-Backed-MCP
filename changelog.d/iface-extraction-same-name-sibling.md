- **Fixed:** `extract_interface_preview` no longer no-ops on every implemented interface of the requested name: it no-ops only when that interface (with its base interfaces) is implemented by every requested member, otherwise it generates the interface beside it, keeps the original implemented, and refuses only a real target conflict (a same-named type already in the target namespace). A reference spelled like the interface that the new interface would capture (the original's, an unrelated same-named type's, one a using alias gave to a differently named type, a downstream project's, each linked copy of a file) is re-pinned to what it bound to; a capture that cannot be re-pinned refuses the preview, naming the file and, where one exists, the line, with a remedy that fits the route (an alias to a generic, nested, tuple, nullable, array, pointer or function-pointer type, or to a namespace; a type visible only through an extern alias or shadowed by a same-named type under the global alias; a reference in a source-generated document; linked copies that differ in text or would pin a name to different types). A preview whose edited files, including a linked copy of one, no longer compile in some project is refused by the compile gate, which names the project and the diagnostic ids with a remedy that fits the causes that applied. A file linked into several projects is edited once and propagated to the other copies only when the route edited a single copy; `extract_interface_cross_project_preview`, `dependency_inversion_preview` and `extract_and_wire_interface_preview` share the re-pin and that targeted propagation, so a linked file the re-pin edited identically in every copy gains no project reference to the interface; `extract_and_wire_interface_preview` still refuses a type that implements an interface of that name. Migration: a caller that relied on the zero-change warning for a same-named interface lacking requested members now gets a generated interface (pick another `interfaceName` or restrict `memberNames` to keep the no-op), and a same-namespace one lacking them is refused as a conflict. Closes `extract-interface-same-name-unrelated-contract-noop`.
