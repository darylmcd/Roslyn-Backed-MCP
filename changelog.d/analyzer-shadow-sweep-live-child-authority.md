- **Fixed:** The abandoned analyzer-shadow sweep no longer deletes a live host's workspace-owned lease on directory age alone. Each lease now holds a sibling ownership marker (`%TEMP%/RoslynMcpAnalyzerShadow/workspace-*/<leaseId>.owner.lock`, taken exclusively before any analyzer reference is bound to the lease and released only when the lease is disposed or its host exits). A foreign sweeper skips a lease whose marker is held, reclaims a stale lease whose marker is released (a disposed lease whose tree could not be deleted, or a crashed host) and then removes the marker, and reaps released markers whose directory is already gone before pruning the workspace directory. A lease directory with no marker whose creator is another live host (an older host that predates markers) is preserved until that host exits; every other markerless child keeps the unchanged age rule. Before this, a late dependency copy into a long-lived lease could be deleted before `LoadFromAssemblyPath`: the Windows no-follow walker aborts at the first entry it cannot open, so a mapped sibling protected only the entries enumerated after it, not the whole subtree. Closes `analyzer-shadow-sweep-live-child-authority`.
