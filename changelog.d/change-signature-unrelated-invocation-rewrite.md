- **Fixed:** `change_signature_preview` add/remove/reorder no longer refuses with "An existing argument has no original semantic parameter binding" when an invocation argument is a null-operation expression such as `x!` or `checked(...)` (this made every preview on `RoslynMcp.slnx`, including `PhysicalPathResolver.CanonicalizeDriveRoot`, fail), and no longer rewrites invocations that do not bind to the edited member: an unrelated call that only carries a caller-info default (for example MSTest `Assert.AreEqual(2, count)` in a file that also calls the edited method) stays byte-identical instead of becoming an explicit named-argument generic call, and only the caller-info parameters whose compiler-supplied value would actually change (line shifts, changed argument text) are frozen, each as one `name: literal` argument. `replace_invocation_preview` no longer misreads such a null-operation argument as a params-expanded element; argument-to-parameter lookup goes through one shared `ArgumentOperationResolver`. Closes `change-signature-unrelated-invocation-rewrite`.
