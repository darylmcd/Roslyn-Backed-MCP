- **Changed:** Interface extraction (`extract_interface_cross_project_preview`, `dependency_inversion_preview`, `extract_and_wire_interface_preview`) now refuses, before any preview token is stored or file written, a generated interface that the receiving project's C# language version cannot parse (collection `params`, `ref readonly` and `scoped` parameters, function pointers; previously a token for an interface failing with CS9202, CS9058, CS8936 or CS8400 was issued). The refusal compiles the final generated declaration under the receiving and the source parse options and lists every distinct compiler id the receiving parse adds, never a prefix; it never changes the receiving project's `LangVersion`. Migration: raise `LangVersion` in the receiving project or extract into a project with a newer language version. Receivers whose language supports the members, and ordinary `params T[]` arrays, are unchanged; the standalone `extract_interface_preview` writes into the source project and is unchanged. The nullable-context refusal likewise now lists every distinct id instead of the first five. Part of `interface-extraction-receiving-language-compatibility`.
