- **Maintenance:** Corrected ADR 0001 (`docs/decisions/0001-locationdto-nested-field-migration.md`) — the producer survey is now scoped per DTO instead of conflating the sets into one count. The original list of five named four genuine `DiagnosticDto` producers plus `MutationAnalysisService.cs`, which is not a `DiagnosticDto` producer at all but the sole `TypeUsageDto` producer; four real `DiagnosticDto` producers (`ScriptingService.cs`, `SnippetAnalysisService.cs`, `UnresolvedAnalyzerReferenceStripper.cs`, `WorkspaceDiagnosticsSink.cs`) were omitted. Corrected: eight `DiagnosticDto` producers, one `SymbolDto` producer (`SymbolMapper.cs`, which double-duties as a `DiagnosticDto` producer and is the sets' only overlap), and one `TypeUsageDto` producer (`MutationAnalysisService.cs`) — nine distinct files for the three flat-field DTOs the migration touches. Stage 1's scoping bullet now cross-references that single enumeration instead of relying on a `DiagnosticDto`-only `rg`, which would have silently missed the sole `TypeUsageDto` producer. Section 2 also states the symmetric null-location rule for producers that resolve line/column but no file path. Closes `adr-0001-location-migration-corrections`.
